# Population Genetics

This repository contains simulations of evolutionary mechanisms for the Population Genetics course at Sorbonne Université. The project is in progress.

The project is conducted in autonomy with no use of generative AI for code generation.

The project contains Jupyter notebooks, each focusing on an aspect of evolution. 

1. Genetic drift : genetic_drift.ipynb
2. _Mutations : in progress_
3. _Varying population sizes : in progress_
4. _Selection : in progress_
